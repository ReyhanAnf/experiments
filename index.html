Cara Menambahkan Eksperimen Baru

git clone & static deploy

Repositori ini dirancang sebagai katalog file HTML mandiri (tanpa build tools yang rumit). Setiap eksperimen cukup berbentuk satu file .html beserta asetnya:

1. Buat File HTML
Tambahkan file seperti game.html atau canvas.html langsung di folder root.
2. Pasang Navigasi Kembali
Tambahkan link <a href="./">Hub</a> di bagian atas agar pengunjung mudah kembali.
3. Daftarkan di Index
Tambahkan kartu eksperimen baru ke dalam index.html lalu commit & push!
